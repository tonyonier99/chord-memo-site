01

想到什麼，先記下來

一句歌詞、一段哼唱、一張照片、一筆塗鴉，先丟進來，不用想怎麼整理。

  • 聲音哼一段或加一段聲音
  • 文字加一句話
  • 照片加一張畫面
  • 塗鴉畫一筆
  • 靈感匣靈感不限數量，想到就存，之後再挑來寫成歌。
  • 回來聽聽你的歌挑一首暫放的靈感，回來聽 30 秒就好。

02

彈到怪和弦，也存得起來

按出你自己的按法，它會幫你認出這是什麼和弦。

  • 自訂按法點格子設定每條弦的按法，✕ = 悶弦、○ = 空弦
  • 看起來像按好之後，馬上告訴你這可能是什麼和弦
  • 存進這首歌彈到喜歡的聲音就存起來；猜不出名字也沒關係，一樣存得起來
  • 和弦譜點小節填和弦，主歌副歌一段一段排好，整份譜一眼看完。
  • 分享整份譜整份譜存成一張圖片分享。

03

錄成一段簡單的 demo

進錄音室之前，先把歌錄出個樣子。

  • 立刻錄音按一下就開始錄。鎖住螢幕、切到別的 App，錄音都不會斷。
  • 錄音留在你手上錄音只存在你的手機和你自己的 iCloud
  • 一軌一軌疊上去主錄音是編曲的第一軌。錄好之後回到這裡，就能一軌一軌疊上去。
  • 靜音與只聽這軌每一軌都能關掉，或只聽這一軌
  • 節拍器錄音時跟著歌的速度打拍子，先響 1 小節預備拍
  • 調音器彈一下就知道準不準。只聽、不錄、不上傳。

其他

  • iCloud 同步（可選）你的作品只同步到你自己的 iCloud 私人空間，由 Apple 保管，開發者無法讀取。
  • 最近刪除不小心刪掉作品怎麼辦？到首頁右上角的「…」選單 >「最近刪除」可以復原。
